# Changelog

Все значимые изменения проекта Timeline Notifier документируются в этом файле.

## [2.0.0] — 2026-10-25 (Stable Release)

### 🚀 Ключевые возможности и архитектура
- **Поддержка серверов в РФ**:
  - Встроенный Docker-сервис `timeline-tg-proxy` (`Flowseal/tg-ws-proxy` v1.3.0) с прямой маршрутизацией Telegram Bot API через IP датацентров Telegram (`149.154.167.220`).
  - Поддержка российских SSL-сертификатов Минцифры (`TIMELINE_VERIFY_SSL=false` по умолчанию).
- **Динамическое расписание занятий (uspu.ru)**:
  - AJAX-парсер с поддержкой 919 академических групп.
  - Режим «Умная неделя»: автоматическое переключение на следующую учебную неделю в выходные (суббота/воскресенье).
  - Компактный формат отображения, защищающий от лимита 4096 символов Telegram.
  - Адаптивная клавиатура навигации по неделям и дням.
  - Автоматическое определение академической группы студента из названий дисциплин Timeline (`EduModuleName`).
  - Фоновый мониторинг изменений расписания с отправкой уведомлений старостам/студентам.
- **Оптимизация для ARM-устройств (Low Power Max)**:
  - Разработано и протестировано на ARMv8 (Allwinner H313/H616 TV Box x96q / Armbian).
  - Проверка дедлайнов 3 раза в день (`8:00`, `14:00`, `20:00` МСК) — процессор спит 99% времени.
  - Жесткие лимиты памяти в Docker Compose: 256 МБ для бота, 128 МБ для tg-proxy (защита от OOM).
  - Подавление избыточных логов APScheduler для сохранения ресурса MicroSD/eMMC флеш-памяти.
  - Кэширование расписания в памяти на 2 часа (снижение нагрузки на сеть и CPU).
  - Веб-сервер Waitress ограничен 2 потоками с минимальным потреблением RAM.
- **Удалённый доступ и администрирование**:
  - Вспомогательный скрипт `scripts/web-tunnel.sh` для быстрого доступа к веб-панели через HTTPS без «белого» IP.
  - iCalendar экспорт дедлайнов (`/export/ical/<user_id>`).
  - Защита веб-панели: CSRF-токены, заголовки CSP, сессионная аутентификация.
  - База данных SQLite: WAL-режим, внешний ключ каскадного удаления, `busy_timeout = 5000`, безопасная автомиграция новых колонок.
