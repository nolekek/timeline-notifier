# Changelog

Все значимые изменения проекта Timeline Notifier документируются в этом файле.

## [3.1.1] — 2026-10-28

### 📅 Редизайн расписания с карточками `<blockquote>`
- **Новое визуальное оформление расписания**:
  - Карточки пар внутри HTML-блока цитаты `<blockquote>` в точном соответствии с новым дизайном.
  - Каждая пара структурирована в 3 строгих и понятных блока:
    - `⏰ Время | Тип пары` (например: `⏰ 09:45-11:20 | конс. перед экз.`)
    - `📖 Название предмета` (очищенное от хвостового типа)
    - `👩‍🏫 Преподаватель 🏫 Аудитория` (сокращённые ФИО и очищенный номер аудитории, при наличии — подгруппа)
  - Аккуратное разделение пар пустыми строками внутри блока дня.
  - Оформление дней без пар: `<blockquote><i>Пар нет, можно отдыхать! 🎉</i></blockquote>`.
  - Улучшенное экранирование и защита от разрыва тегов Telegram в недельном виде при ограничении длины.

## [3.1.0] — 2026-10-28 (Stable Release)

### 📋 Полный парсинг заданий прямо в Telegram (Full Assignment Parsing)
- **Расширение схемы данных `WorkItem`**:
  - `point_name` (тема / контрольная точка)
  - `control_text` (полный текст задания преподавателя)
  - `points` (текущие и максимальные баллы, например «5 из 5» или «0 из 10»)
  - `teacher_note` (рецензия / комментарий преподавателя)
  - `unavailability_reason` (информация об ограничениях доступности задания)
- **Детектор файлов и материалов (`extract_file_attachments`, `extract_urls`)**:
  - Автоматическое распознавание названий прикреплённых файлов с расширениями (`.pdf`, `.docx`, `.zip`, `.xlsx`, `.pptx` и др.) из текста заданий и рецензий преподавателя.
  - Отображение моноширинных бейджей файлов `📁 Файлы к заданию: <code>имя.расширение</code>` и кликабельных ссылок на материалы.
  - Чёткая индикация, если файл отсутствует и задание сформулировано текстом.
- **Безопасная автомиграция**: автоматическое добавление новых колонок в SQLite при старте без риска для существующих данных.
- **Парсер SendGrid**: извлечение всех детальных полей при каждом штатном опросе без дополнительных сетевых запросов к сайту.
- **Синхронизация баллов и рецензий**: фоновый мониторинг изменений баллов и комментариев преподавателей с уведомлениями студенту.

### 📱 Интерактивные карточки и UI 3.0
- **Интерактивный список `/status`**:
  - Отображение темы (`point_name`), срока, статуса и баллов (`points`).
  - Ряд инлайн-кнопок быстрого просмотра прямо под списком: `[📋 #1]`, `[💬 #2]` (с подсветкой наличия рецензии преподавателя).
- **Экран детального просмотра работы (`work_view|<id>`)**:
  - Карточка задания с цитатами через Telegram HTML-тег `<blockquote>`.
  - Блоки текста задания преподавателя, рецензии и условий доступности.
  - Кнопка прямого перехода `[🌐 Открыть в Timeline]` для скачивания файлов и сдачи работ.
  - Защита от лимита 4096 символов Telegram (безопасное усечение сверхдлинных заданий).
- **Команды прямого доступа**:
  - `/task <id>` или `/work <id>` — мгновенный просмотр конкретного задания по ID.
  - `/find <текст>` — расширенный поиск не только по предметам, но и по темам контрольных точек и тексту заданий.

### 🔮 Ежедневный студенческий гороскоп (`/horoscope`)
- **12 знаков зодиака**: Овен, Телец, Близнецы, Рак, Лев, Дева, Весы, Скорпион, Стрелец, Козерог, Водолей, Рыбы.
- **Детерминированная генерация**: сидирование от даты и знака (`date.today()`, `sign`), исключающее случайную смену прогноза в течение дня.
- **Студенческий юмор**: автоматы, дедлайны в 23:59, пары к первой паре, настроение преподавателей, кофе из автомата, выравнивание текста по ширине.
- **Интеграция в утренний дайджест**: персональный гороскоп выбранного знака в 08:00 (настраивается в `/profile`).

### 🐾 Темизация и секретная локализация
- **Поддержка темы `:3` (`/femboy`)**:
  - Адаптация интерактивных кнопок (`[🐾 #1]`, `[🎀 #2]`, «🐾 Заданьице», «🎀 Комментарик препода»).
  - Отдельный пушистый пул студенческих гороскопов и советов.

## [2.1.0] — 2026-10-26 (Stable Release)

### 🛠 Исправления и устойчивость сессий
- **Фильтрация долгов (> 5 дней)**: Просроченные работы со сроком сдачи старше 5 дней автоматически исключаются из вкладки долгов (`/overdue`) и фоновых алертов, но сохраняются в общем статусе семестра (`/status`).
- **Иммунитет сданных работ**: Любая работа со статусом «Зачтена», «Проверена» или «Отправлена» гарантированно исключена из просроченных (`is_overdue = False`).
- **Сброс сессионных cookies**: В `TimelineAuth` добавлена принудительная очистка устаревших кук перед OAuth-авторизацией для предотвращения зацикливания редиректов (`REASON_FLOW`).
- **Подавление разовых ошибок**: Временные ошибки входа и сбои сессии скрываются из пользовательского интерфейса (`/status`, `/profile`) до тех пор, пока подряд не накопится 3 неудачные попытки (`fail_streak >= 3`).
- **Автосброс счетчика неудач**: При первой же успешной проверке счетчик `fail_streak` сбрасывается в 0.

### 🔍 Диагностика и юмор
- **Русский моноширинный блок ошибок**: К сообщениям об ошибках добавлен стандартизированный диагностический футер:
  `<code>Модуль: ... | Ошибка: ... | Попытки: N/M | Время: HH:MM:SS MSK</code>`
- **Пул извинений**: 25 душевных и вежливых извинений при сбоях («Виноват не я, упали сервера Таймлайна», «Сборщик помер... Простите, родные, мы всё починим»).
- **Расширение юмора**: Общий пул студенческого сарказма расширен до 371 фразы в 34 категориях.

### 🛡 Админ-панель и режим технических работ
- **Интерактивная диагностика**: Кнопки в `/admin` для проверки задержки БД, статуса планировщика APScheduler, пинга Telegram API и теста входа в ЭИОС.
- **Режим техработ (Maintenance Mode)**:
  - Двухэтапная активация (кнопка в админке + команда подтверждения `/maintenance_confirm`).
  - Мгновенное отключение одной кнопкой.
  - Полное подавление фоновых уведомлений студентам во время техработ.
  - Перехват любых действий обычных пользователей с выдачей экрана техработ и рандомной шутки из специального пула (35 уникальных фраз).
  - Администратор (`ADMIN_CHAT_ID`) сохраняет неограниченный доступ для отладки.
- **Инструмент рассылки**: Команда `/broadcast <текст>` для экстренных системных объявлений.

### 🐾 Секретная локализация (Пасхалка)
- **Секретная команда `/femboy`**: Разблокирует тумблер смены темы в профиле (`/profile`).
- **Милое оформление**: Динамическая смена кнопок меню («🐾 Статусик :3», «🐾 Хвостики-долги», «🐾 Потыкать лапкой», «🎀 Профиль :з», «📅 Расписаньице :3») и отдельный изолированный пул милых шуток (лапки, котики, мягкие напоминания).
- **Счетчик пользователей**: Отображение количества активных пользователей фембой-темы в сводке `/admin`.

## [2.0.0] — 2026-10-25 (Stable Release)

### 🚀 Ключевые возможности и архитектура
- **Поддержка серверов в РФ**:
  - Встроенный Docker-сервис `timeline-tg-proxy` (`Flowseal/tg-ws-proxy` v1.3.0) с прямой маршрутизацией Telegram Bot API через IP датацентров Telegram (`149.154.167.220`).
  - Поддержка российских SSL-сертификатов Минцифры (`TIMELINE_VERIFY_SSL=false` по умолчанию).
- **Динамическое расписание занятий (uspu.ru)**:
  - AJAX-парсер с поддержкой 919 академических групп.
  - Режим «Умная неделя»: автоматическое переключение на следующую учебную неделю в выходные (суббота/воскресенье).
  - Компактный формат отображения, защищающий от лимита 4096 символов Telegram.
  - Адаптивная клавиатура навигации по неделям и дням.
  - Автоматическое определение академической группы студента из названий дисциплин Timeline (`EduModuleName`).
  - Фоновый мониторинг изменений расписания с отправкой уведомлений старостам/студентам.
- **Оптимизация для ARM-устройств (Low Power Max)**:
  - Разработано и протестировано на ARMv8 (Allwinner H313/H616 TV Box x96q / Armbian).
  - Проверка дедлайнов 3 раза в день (`8:00`, `14:00`, `20:00` МСК) — процессор спит 99% времени.
  - Жесткие лимиты памяти в Docker Compose: 256 МБ для бота, 128 МБ для tg-proxy (защита от OOM).
  - Подавление избыточных логов APScheduler для сохранения ресурса MicroSD/eMMC флеш-памяти.
  - Кэширование расписания в памяти на 2 часа (снижение нагрузки на сеть и CPU).
  - Веб-сервер Waitress ограничен 2 потоками с минимальным потреблением RAM.
- **Удалённый доступ и администрирование**:
  - Вспомогательный скрипт `scripts/web-tunnel.sh` для быстрого доступа к веб-панели через HTTPS без «белого» IP.
  - iCalendar экспорт дедлайнов (`/export/ical/<user_id>`).
  - Защита веб-панели: CSRF-токены, заголовки CSP, сессионная аутентификация.
  - База данных SQLite: WAL-режим, внешний ключ каскадного удаления, `busy_timeout = 5000`, безопасная автомиграция новых колонок.
