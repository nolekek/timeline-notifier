# Timeline Notifier — Правила разработки и эксплуатации

## Применение обновлений кода в Docker (Deploy Invariant)
В этом проекте исходный код (`app/`, `run.py`) запекается в Docker-образ на этапе сборки (`COPY . .` в `Dockerfile`). В тома монтируется исключительно каталог базы данных и логов (`./instance:/app/instance`). Live bind-mount каталога с кодом отсутствует.

- **СТРОГО ЗАПРЕЩЕНО** рекомендовать `docker compose restart` для применения изменений в Python-коде, шаблонах или статических файлах.
- При любых изменениях кода после `git pull` **ВСЕГДА** указывать команду обязательной пересборки:
  ```bash
  docker compose up -d --build bot
  ```
  (или `docker compose up -d --build`)
- Команду `docker compose restart` допустимо использовать **только** для перезапуска зависшего процесса или при операциях с базой данных SQLite на хосте без изменения кода приложения.
