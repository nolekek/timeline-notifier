# ЧИТАТЬ ПЕРВЫМ

Это **Timeline Notifier** — Telegram-бот, который следит за дедлайнами работ в Timeline УрГПУ
за многими студентами сразу. Студент пишет боту `/start`, один раз вводит свой логин/пароль
ЭИОС — дальше бот сам логинится на сайт и присылает ему напоминания (новые работы, смена
статуса, 48/24/12 часов, просрочка). Веб-страница — админ-панель, студенты ей не пользуются.

Поднимается **одним контейнером**. Полная документация — в `README.md`, устройство парсера —
в `docs/parser-notes.md`.

---

## Что нужно на сервере

* Docker с плагином compose (`docker compose version` должен отвечать).
* Всё. Python, зависимости и timezone — внутри образа.

## Установка (5 минут)

```bash
# 1. Распаковать архив (это zip; если нет unzip — apt install unzip)
sudo mkdir -p /opt
sudo unzip timeline-notifier-docker.zip -d /opt
cd /opt/timeline_notifier

# 2. Конфиг
cp .env.example .env

# 3. Ключи (вставь вывод в .env)
python3 -c "import secrets; print('SECRET_KEY=' + secrets.token_hex(32)); print('CRED_KEY=' + secrets.token_hex(32))"
nano .env
```

В `.env` обязательно заполнить:

| Переменная | Что писать |
|---|---|
| `SECRET_KEY`, `CRED_KEY` | вывод команды выше. **`CRED_KEY` потом не менять** — иначе пароли студентов не расшифруются |
| `ADMIN_USER`, `ADMIN_PASSWORD` | логин/пароль к админке. Пустой пароль = админка открыта всем, так нельзя |
| `ADMIN_CHAT_ID` | твой telegram-id (узнать: @userinfobot) — включает боту команды `/admin`, `/broadcast` |
| `APP_UID`, `APP_GID` | `id -u` и `id -g`. Если у тебя `1000` — можно не трогать |

```bash
# 4. Запуск
mkdir -p instance
docker compose up -d --build
docker compose logs -f
```

В логе должно появиться `Планировщик запущен: тик 60 сек`, а после ввода токена —
`Бот: @имя_бота (название)`. Выход из логов — `Ctrl+C` (контейнер продолжает работать).

## Первый запуск бота

1. Открыть `http://<IP-сервера>:5000/` (спросит логин/пароль из `.env`).
2. Вписать **Telegram Bot Token** (его пришлёт владелец бота отдельно — в архиве его нет),
   галку «Перезапустить бота с новым токеном» оставить и сохранить.
3. В логе снова должно появиться `Бот: @...`.
4. Написать боту в Telegram `/start`, отправить свой логин ЭИОС и пароль — бот проверит вход
   и покажет список работ. Первый студент — это ты.

## Как понять, что всё работает

```bash
docker compose ps                                  # STATUS: Up ... (healthy)
docker compose logs bot | grep -E "Бот:|Планировщик|Проверка chat_id"
docker compose exec bot python tests/smoke_test.py # самотест логики: должен быть OK
docker compose exec bot date                       # время и TZ (ждём MSK, +0300)
```

Через 5 минут после регистрации в логе появится `Проверка chat_id=***NNNN: работ N`.

## Три грабли, из-за которых чаще всего «не работает»

1. **`unable to open database file`** — контейнер и папка `instance/` принадлежат разным
   пользователям. Впиши в `.env` свои `APP_UID`/`APP_GID` (`id -u`, `id -g`) и перезапусти:
   `docker compose up -d`.
2. **Бот не видит команды, хотя уведомления приходят** — с этим токеном работает **второй**
   инстанс (на чужой машине или локальный `python run.py`). Telegram отдаёт апдейты только
   одному: в логе будет `409 Conflict`. Останови лишний. И никогда не запускай
   `docker compose up --scale bot=2` — планировщик и поллинг удвоятся.
3. **`Не удалось получить getMe`** — с сервера недоступен `api.telegram.org`. Проверь:
   `docker compose exec bot python -c "import requests;print(requests.get('https://api.telegram.org',timeout=10).status_code)"`.
   Если не отвечает — подними прокси (tg-ws-proxy на хосте, см. `deploy/`), добавь в `.env`
   `TELEGRAM_PROXY=socks5h://host.docker.internal:1080` и раскомментируй в `docker-compose.yml`
   блок `extra_hosts: host-gateway`. Альтернатива — свой мирор Bot API в `TELEGRAM_API_BASE`.

## Обновление и бэкап

```bash
git pull && docker compose up -d --build        # если разворачивал через git
cp instance/timeline.db ~/timeline-$(date +%F).db   # бэкап: просто копия файла
docker compose down                              # остановить (данные в ./instance остаются)
```
